# 📘 Project Overview

## 🎯 Objective
To design and implement a cloud-based architecture capable of hosting both static and dynamic web applications using AWS services.

---

## 🧩 Problem Statement
Traditional hosting solutions lack scalability, automation, and real-time monitoring capabilities. This project addresses these limitations using AWS cloud-native tools.

---

## 💡 Solution
A hybrid architecture was implemented:
- Static content hosted on S3
- Dynamic content served from EC2
- Automation handled via AWS Lambda
- Data stored in DynamoDB
- Monitoring via CloudWatch

---

## 🌟 Key Benefits
- High availability
- Cost efficiency
- Scalability
- Automation
- Security
